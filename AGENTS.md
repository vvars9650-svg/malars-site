# МАЛАРС — правила локальной работы

## Browser / Computer Use

- Интерактивный просмотр и визуальные проверки localhost выполнять только во встроенном браузере ChatGPT/Codex.
- Не открывать URL через Start-Process, explorer, системный браузер по умолчанию или внешние окна Edge/Chrome.
- Изолированные headless-тесты без внешних окон разрешены отдельно; их результаты не заменяют визуальную проверку встроенного браузера или приёмку владельцем.
- Если встроенный браузер недоступен, записать точную причину блокера; не использовать внешний браузер как fallback.
- Для локального preview использовать только синтетические данные и локальную API-имитацию. Внешние запросы за справочниками запрещены без отдельного разрешения.
- Не менять main, backend/API, TEST/PROD и не выполнять deployment в рамках MAL-20261110-01. TASK-ID оставлять открытым до приёмки владельцем и команды «Закрываем задачу».
