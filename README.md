# МАЛАРС — MVP-платформа

Рабочий сайт проектного интегратора МАЛАРС.

## Архитектура

Текущая MVP-система состоит из:

- GitHub Pages — публикация сайта;
- Google Apps Script — backend форм;
- Google Sheets — операционная база данных;
- Google Drive — хранение файлов проекта;
- GitHub — источник истины по коду.

## Структура репозитория

- `index.html` — основная структура сайта;
- `styles.css` — стили и адаптация;
- `script.js` — клиентская логика;
- `apps-script/Code.gs` — эталонный код backend;
- `CNAME` — подключение домена.

## Формы сайта

### Заказчик

Передаёт:

- контактные данные;
- задачу;
- географию;
- срок;
- исходные документы.

Заявки сохраняются в Google Sheets:

`Заявки заказчиков`

Файлы сохраняются в Google Drive внутри проекта МАЛАРС.

### Участник

Передаёт:

- организационную форму;
- контакты;
- компетенции;
- объекты;
- географию;
- документы и ресурсы.

Основная база:

- `Участники v2`;
- `Компетенции v2`;
- `Типы объектов v2`;
- `География v2`;
- `Документы v2`.

## Развертывание

Frontend:

GitHub → main → GitHub Pages.

Backend:

Изменения `apps-script/Code.gs` требуют отдельного обновления существующего Google Apps Script Web App deployment.

Обновление GitHub не выполняет автоматический deployment Apps Script.

## Источники истины

- код: GitHub;
- данные: Google Sheets;
- файлы: Google Drive внутри папки `Проектный интегратор`;
- решения: MASTER-документы проекта.

## Важно

Сайт находится на стадии MVP.

Не используются:

- личные кабинеты;
- открытый каталог подрядчиков;
- сложная CRM;
- автоматический подбор исполнителей.

Цель платформы — провести первые реальные проекты через модель МАЛАРС и подтвердить экономику процесса.
