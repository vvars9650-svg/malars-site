# МАЛАРС — план пересборки frontend MVP

## Текущая архитектура

Сайт работает через несколько слоёв:

- index.html — базовая разметка;
- styles.css — стили;
- script.js — загрузчик версий;
- script-core.js — основная логика форм и данных;
- site-upgrade.js — слой обновления интерфейса;
- site-latest.js — последний слой патчей.

## Цель

Получить одну чистую frontend-версию без цепочки runtime-патчей, сохранив текущую бизнес-логику MVP.

## Новая целевая структура

```
index.html
styles.css
js/
  app.js
  forms.js
  data.js
apps-script/
  Code.gs
```

## Правила миграции

1. Не менять бизнес-логику во время переноса.
2. Не удалять текущие файлы до успешного теста новой версии.
3. Сначала собрать копию текущего рабочего состояния.
4. Проверить:
   - форму заказчика;
   - загрузку документов;
   - форму участника;
   - сохранение компетенций;
   - географию;
   - запись в Google Sheets.

## Карта переноса

### script-core.js

Перенести в forms.js:
- отправку форм;
- работу wizard;
- валидацию;
- связь с Apps Script.

### site-upgrade.js

Перенести:
- брендовые изменения;
- мобильную навигацию;
- дополнительные проверки;
- обновления формы заказчика.

### site-latest.js

Перенести:
- организационные формы;
- географию;
- ОПО;
- контакты;
- логику "Работаем по всей России".

### script.js

После миграции становится не нужен.

## Контрольная точка

Старый сайт продолжает работать до полного прохождения тестов новой версии.
