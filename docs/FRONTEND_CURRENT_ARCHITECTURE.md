# Текущая архитектура frontend МАЛАРС

## Рабочая цепочка MVP

index.html
  -> script.js
  -> site-upgrade.js
  -> site-latest.js
  -> script-core.js

## Роли файлов

### index.html
Базовая HTML-разметка сайта.

### styles.css
Основные стили.

### script.js
Загрузчик версий. Временный слой совместимости.

### site-upgrade.js
Первый слой обновлений интерфейса:
- бренд;
- мобильная навигация;
- расширения форм.

### site-latest.js
Последний слой изменений:
- организационные формы;
- география;
- ОПО;
- контакты;
- дополнительные улучшения.

### script-core.js
Основная логика:
- справочники;
- формы;
- отправка данных;
- связь с Apps Script.

## Целевая миграция

После стабилизации:

index.html
styles.css
js/app.js
js/forms.js
js/data.js
apps-script/Code.gs

Без изменения бизнес-логики.
