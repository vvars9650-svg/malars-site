Сборщик импортируется без запуска TEST main; origin/API принудительно localhost.
Никаких cloud, deploy, загрузки данных или запуска workflow нет.
Встроенный сервер скопирован из рабочего локального preview без изменений логики.
SQLite создаётся только локально при запуске; заказчик хранится в памяти.
Не вводите реальные данные. Не коммитьте generated, SQLite, логи и browser-profile.

В новом браузере/на другом ПК без этого кэша полная проверка городов BLOCKED.

194 записи с несопоставленным регионом не принимаются заказчиком. Полнота всего справочника РФ не доказана.
Никакие города из сети автоматически не скачиваются. При отсутствии кэша новый preview показывает ошибку справочника. Новая копия preview воспроизводит код и API-имитацию,
но не пользовательский кэш/fixture/предзаполнение. Не выдавайте её за полное исходное окружение.
