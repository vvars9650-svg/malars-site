## Принятый интерфейс

1. На уровне 1 шесть направлений с чекбоксами-заголовками и краткими пояснениями.
2. Уровень 2 содержит ШЕСТЬ разделов. Отдельные «Этапы и пакеты работ» удалены.
3. В разделе 2 последовательные внутренние шаги: подсистемы/специализации → виды
   работ для выбранных подсистем → способ выполнения и масштаб работ.
4. Поставка — вид работ внутри подсистемы; общей галочки поставки здесь нет.
   Поле «Другие работы» в разделе 2 убрано. Старые данные не удаляются.
5. «Масштаб работ» и «Что именно можете закрыть и с чьим участием? Пример»
   перенесены из бывшего раздела 3 в конец раздела 2. Пример НЕОБЯЗАТЕЛЕН;
   масштаб и способ выполнения обязательны.
6. Профильные направления видны сразу; остальные под спокойным «Другие направления».
   Поиск глобальный, включая сокращения и старые коды. Выбор вне профиля добавляет
   направление в mainCategories. Внутренние коды скрыты из видимого интерфейса.
7. Виды работ ограничены смыслом: балансировка ОВиК и другие ПНР-услуги — только
   ПНР; обследования/изыскания — обследование; проектирование/расчёты — проектирование.
   Старые неприменимые операции сохраняются с требованием явно уточнить выбор.
8. Варианты — карточки с тонкой рамкой. Клик по свободному краю карточки переключает
   checkbox/radio; выбранное состояние выделяется фоном и рамкой.
9. Ошибки: красная подсветка блока, яркий текст у «Далее», прокрутка к ошибке.
   Для видов работ у блока только «Выберите виды работ», у кнопки:
   «Выберите виды работ для каждой подсистемы», без перечисления вариантов.
10. Проверка конкретной специализации выполняется внутри раздела 2. На итоговом
    экране проблемная карточка выделяется; «Исправить раздел» открывает нужный шаг.
    Содержимое разделов 3–6 пользователь принял, не перерабатывать без запроса.
11. Прокрутка: выбор пунктов остаётся на месте; переходы вперёд/назад — к началу
    формы под шапкой; проверка ошибки — к проблемному месту. Последняя правка:
    preventScroll при восстановлении фокуса, сохранение scrollY при перерисовке,
    сброс старого validationError на изменение, отмена отложенной прокрутки при выборе.

## Пересборка — осторожно

Сборщик по умолчанию генерирует TEST-config. Для localhost запускать через runpy
и менять globals main: OUTPUT=<preview root>/frontend, API_BASE_URL и TEST_ORIGIN
на http://localhost:8765. Это локальная сборка, не deployment.
После пересборки заново включить local prefill flag, восстановить локальную
надпись об имитации отправки в test-runtime.js и локальный текст результата
в generated participant-flow.js. Последние мелкие правки обновлялись напрямую
в source и generated файлах; не брать устаревшие файлы из .local-preview/changes.
